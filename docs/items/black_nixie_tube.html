黑色辉光管

详细教程

怎么用

把辉光管贴在墙面、机壳或仪表板上，它就是一个单字符的显示屏。被红石充能时按信号强度显示 0 到 15，信号越强数字越大，断开就熄灭。

要显示文字，先用剪贴板写好内容再右键它，管子会记住这段文本；要显示机器数据，就用显示链接器把转速表、应力表或存量转信器接过来。染成黑色后，未通电的管壁几乎与深色机壳融为一体。

这个颜色适合哪

黑色辉光管属于暗色控制室与夜班场景：深板岩、黑色机壳、深色玻璃砌成的墙面，平时是一排纯装饰，触发时才亮出读数，像老设备在暗处待机。夜间列车的驾驶室、地下室的服务器机柜、配电间的状态位都很适合，它不会在黑暗里抢走你的视线。

搭配与常见坑

和灰色、淡灰色混排时，黑色那几支自然成为留白，适合放在读数序列的首尾。注意它在昏暗环境里可读性最差，别把关键警报交给它：警报用红色，黑色留给待机位和装饰数字。
