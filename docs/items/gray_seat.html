灰色坐垫

Gray Seat

灰色坐垫：办公室与车间休息角的椅子。

参数

交互右键坐下 / 潜行起身
合成羊毛 + 木台阶
换色染料换色

详细教程

怎么用

坐垫右键坐下、潜行起身；羊毛加木台阶合成，染料换色。坐下时人物高度下降，正好对着办公桌或操作台。装在移动结构上时，玩家会跟着一起走。

它比楼梯更适合当椅子：占地一格、四面都能坐、不会挡住走道。

这个颜色适合哪

灰色坐垫适合办公室、车间休息角、控制室：配安山机壳、铁桌、文件柜，是很典型的工业办公场景。做一排等位椅也很合适，灰色不抢眼，谁坐都不突兀。

灰坐垫比淡灰坐垫实、比黑坐垫轻：办公室和控制室用它。它和安山机壳几乎同色，做工业风时最容易融进背景；配铁桌和文件柜才看得出是工位。

搭配与常见坑

灰坐垫在灰色地板上会「消失」，加一块深色地毯或木质底座会更像一件家具。它和淡灰色太接近，同一间屋子里别混用。

灰坐垫配铁桌最像工位，配木桌就会显得像临时拼的；一排等位椅之间加扶手，坐满时也不会互相挤。
