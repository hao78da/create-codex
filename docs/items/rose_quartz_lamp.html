玫瑰石英灯

镶红石的玫瑰石英灯。

参数

材料磨制玫瑰石英 + 红石 + 锌锭
触发红石信号
类型灯具

详细教程

怎么获得

工作台里无序摆三样：一块磨制玫瑰石英、一份红石粉、一块锌锭，就出一盏玫瑰石英灯。磨制石英要先用砂纸打磨，锌锭则来自锌矿。三样材料丢进工作台任意格都行，不用记图案。

三样东西分别对应灯体、线路和触点，缺一样都合不出来。一次多做几盏，铺一条走廊往往要七八个，单做一盏来回跑很烦。通上红石才亮，跟红石灯一样信号一断就灭。

怎么用

接上红石信号就亮，信号一断就灭，逻辑和红石灯一样，只是光色偏粉。嵌在地面砖缝里、台面下沿、楼梯踢面，光会从缝里透出来，比挂灯笼干净。亮度比火把温和，做室内灯带时用它打底。

配合玫瑰石英瓦使用效果最好：瓦面开一格放灯，四周留缝，白天是一块淡粉石材，晚上整片亮起来。售票厅、展厅、浴室都吃这一套。锌锭换成铁锭做不出同样的灯，材料别记混。

常见坑

它不吃持续旋转，也不认应力，只认红石信号；别把转轴怼上去指望它转起来发光。信号源可以是拉杆、按钮、侦测器，接法按普通红石灯来。红石粉只要一份，放多了合成表反而对不上。

灯是整块发光的，嵌进地面时要留出散热格，否则贴图会和瓦面打架，看着像贴歪了。铺之前先在平地上试摆一格，确认缝对得上。磨制石英得先用砂纸打磨，普通玫瑰石英不认。

官方教程 · 玫瑰石英灯

  1. 玫瑰石英灯通入红石信号后会处于激活状态
  2. 它们之后会继续产生红石信号
  3. 当多盏灯排成一组时……
  4. ……激活一盏灯会集中信号给它，并熄灭其余的灯
  5. 比较器根据到激活的灯的距离产生输出
  6. 灯也可以用扳手手动开关
