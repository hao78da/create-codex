空的烈焰人燃烧室

Empty Blaze Burner
create:empty_blaze_burner物品机器与加工

没点火的时候是只铁笼子。

参数

材料4 铁板 + 下界岩
用途加热源空壳
激活装入烈焰人

详细教程

怎么获得

工作台摆成十字：上下左右各一块铁板，中心一格下界岩，合出一只空的烈焰人燃烧室。铁板要压板机压，下界岩去下界挖。四块铁板围一块下界岩，摆成十字。

空壳本身不能加热，必须往里塞一只烈焰人才算数：手持烈焰人燃烧室对着它右键，或者用发射器把烈焰人装进去。装好之后它才变成能点火的燃烧室。空燃烧室点不着，得先喂烈焰蛋糕。

怎么用

空壳可以先摆位置：放在搅拌器、压块机、混合器底下当热源位，等有烈焰人再装。摆好之后不用拆，直接拿烈焰人右键就能激活。装在下界岩上方或机器侧面，接口朝下。

它也能当装饰，铁笼子里空着，放在工厂角落像待机的炉子。摆在产线上时记得先留出上方空间，装烈焰人之后火焰会往上冒。没点着之前它只是个铁架子，别当熔炉用。

常见坑

空壳不会自己热，别把锅架在上面等它烧——没有烈焰人就没有热量。很多人做到这一步以为坏了，其实是少装了一只。下界岩是核心，换成圆石合不出来。

装烈焰人之前别先放烈焰蛋糕，空壳吃不下；顺序是先装人、再点火、最后才是喂蛋糕。搞反了蛋糕会掉在地上。拆之前先把蛋糕清掉，不然会浪费一份燃料。

官方教程 · 使用空的烈焰人燃烧室

  1. 手持空的烈焰人燃烧室右击烈焰人来抓取烈焰人
  2. 或者，可以直接从烈焰人刷怪笼中收集烈焰人
  3. 这样，你便有了一个可供部分机器加工的热源
  4. 如果是为了美观，空的烈焰人燃烧室也可以被打火石点燃
  5. 你可以使用注入了灵魂的物品转化这种火焰
  6. 但是，没有烈焰人，这样的火焰并不足以用于工业级加热工作
