丛林木窗户

Jungle Window
create:jungle_window方块装饰与建筑

丛林木窗户，红棕粗框，热带建筑的窗。

参数

材质丛林木
类型窗户（整块）
合成3 木板 + 1 玻璃 → 2

详细教程

怎么获得

用丛林木板三面包住一块玻璃，上方一块、下方左右各一块，合成一次得到 2 块窗户。丛林原木在丛林生物群系里成片生长，砍起来很快。

它的板色是偏红的棕，纹理比橡木粗，看着更“野”。

怎么用

它适合热带和探险题材：丛林神庙、雨林村落、码头仓库、探险队的营地。红棕框配潮湿的苔石、藤蔓、深绿树叶非常对味。

因为颜色重，它不太适合大面积白墙，但很适合做“被树影遮住的老房子”那种窗。

搭配

配丛林木板、苔石砖、深色橡木、丛林木窗户板；想加亮点，就用砂岩或橙色陶瓦做窗台。

如果墙面全是绿色植物，红棕窗框反而会成为视觉支点，比浅色窗更抓眼。

红棕框最好和苔石、藤蔓、深绿树叶一起出现；如果周围全是灰石，它会显得脏。给它配一块砂岩窗台，颜色立刻被提起来，整扇窗就有了落点。
