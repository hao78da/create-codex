Create Nuclear

附属模组
机械动力：原子核动（Create Nuclear）…

这是什么

机械动力：原子核动（Create Nuclear） 是一个将整个核能系统添加到 机械动力 的附属 Mod。添加了铀矿及其精炼过程，以及因核污染形成的一系列方块和生物。该模组的反应堆可以为机械动力产生超过 100 万的应力…

命名空间：createnuclear　1.20.1 版本：本页物品与配方直接取自该版本的 jar。
