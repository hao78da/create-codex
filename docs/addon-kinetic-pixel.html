Kinetic Pixel

附属模组
用 Create 产线造火器：枪管、激发器、各种弹药

这是什么

把 Create 的加工体系接到轻武器上：抗压板、弹丸管、激发器、储气筒、各类蓝图，最后在火器工台组装成枪。素材链很长，适合喜欢「造产线」的人。

命名空间：kinetic_pixel　1.20.1 版本：本页物品与配方直接取自该版本的 jar。
