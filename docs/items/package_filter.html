包裹过滤器

只放行某类包裹的筛子。

参数

材料2 锌粒 + 羊毛
用途包裹分流
重置自身无序合成

详细教程

怎么获得

工作台横着放三格：左右各一颗锌粒，中间一格羊毛，合出一只包裹过滤器。锌粒由锌锭拆成，羊毛随便什么颜色都行。两颗锌粒加一团羊毛，摆成一条横线。

它还有一条洗白配方：单独把用过的过滤器放进工作台，就能清掉里面记下的过滤条件，反复使用不消耗。做产线前先做两三只，按颜色分开。它装在打包机或漏斗上，只让指定包裹通过。

怎么用

把它贴在打包机、拆包机或传送带口上，它会只让符合设定的包裹通过，其余原路退回。设定方式是对着它放入一个样板包裹，之后同类包裹才认。把要过滤的包裹放进界面里登记，别超过它能记的数量。

做分流线时，一台机器只能管一种规则；要分三种包裹就并排放三只，各自挂在不同的支线上。过滤器之间留一格，别挤在一起挡住包裹路径。登记错了就整条线卡住，先用一个包裹试。

常见坑

样板必须是包裹本身，塞普通物品不会被记住。放错样板后要先用洗白配方清空，再重新贴一次，否则它一直按旧规则拦。和它自己的无序配方一起用时等于清空过滤。

它不消耗包裹也不拆包，只是筛；别把它当拆包机用。真正拆开包裹的还得是拆包机或手工右键。羊毛做滤芯，换成别的纤维合不出来。包错时把过滤件拆下来重放，比改界面快。
