轴向底盘二号

Secondary Linear Chassis
create:secondary_linear_chassis方块动态结构与载具

换了个方向的轴向底盘。

参数

材料线性底盘 1:1
类型动态结构底盘
方向轴向

详细教程

怎么获得

工作台里把一块线性底盘无序一放，就换成轴向底盘二号，1:1 互换不损耗。它不是新方块，只是同一块底盘换了个朝向。一块线性底盘放进工作台任意格，换来的就是次级版本。

两种底盘外形几乎一样，只有纹路方向不同；放下去之后朝哪边，决定它把结构连成一条线还是连成一片。它没有自己的形状，铺开来只是一片薄板。

做装配前先想好结构走向，底盘方向错了，整座机器装出来就是歪的。贴墙时它比主底盘更薄，适合给结构包边。它不能当主底盘用，承重的活还得交给线性底盘。

怎么用

它把方块连成一条轴：沿纹路方向延伸，把整排方块绑成一个动态结构。做矿车、电梯、旋转平台时，用它确定结构的主方向。两块次级底盘叠起来不会合并，位置要手动对齐。

和径向底盘配合，一个管直线、一个管半径，能把不规则的结构也抓牢。底盘之间要贴着放，中间隔一格就断开了。拆结构时它会跟着整台装置一起散掉。

装配站抓的是底盘，不是方块本身；结构里没有底盘，扳手取不下来。它不提供动力，只负责把方块连成一体。想让它跟着动，得先贴在轴承或底盘上。单独悬空摆着时它什么也不做。

常见坑

两块底盘方向不一致时，装配出来的结构会分成两半，动起来各走各的。装之前统一朝向，别随手乱放。铺底盘前先想好尺寸，改起来要整片拆。整片拆下来的材料能回收，别直接丢进岩浆。

它不是机器，不接动力也不传导旋转；别把它当轴用。想传动还得接传动轴和齿轮。和主底盘混用时注意方向，薄的那面永远朝外。同一面墙上混两种厚度会看出高低差。

拆结构时先拆底盘，硬敲方块会把整个结构打散，掉一地还要重新装。底盘铺太多会拖慢装配，够用就行。一台装置铺三四块就够，堆多了反而难拆。铺多了拆起来更费时间。

官方教程 · 成组移动轴向底盘

  1. 相邻的轴向底盘可以相互连接在一起
  2. 其中的一个底盘若被移动，其余的底盘也会跟着移动
  3. 不同种类的底盘，或者是朝向不一致的底盘，将不会相连

官方教程 · 使用轴向底盘黏合方块

  1. 它的外露面可以变为黏性面
  2. 再次点击黏性面，可以将它的对面也变得具有黏性
  3. 空手潜行右击可以移除此面的黏性物
  4. 黏性面可以将此面前方的一长条方块黏住
  5. 使用扳手可以精确控制底盘的影响范围
  6. 按住 Ctrl 以调节所有底盘的影响范围
  7. 若想让底盘的其他面也能粘方块，你需要用到强力胶
  8. 利用这些机制，任何形状的结构都可以作为动态结构移动
