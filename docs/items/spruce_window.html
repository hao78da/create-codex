云杉木窗户

Spruce Window

云杉木窗户，冷褐框线，北欧木屋的窗。

参数

类型窗户（整块）

详细教程

怎么获得

用云杉木板三面包住一块玻璃：上方一块、下方左右各一块，合成一次得到 2 块窗户。云杉在针叶林和雪原成片生长，是最不缺的木料之一。

它的板色是深褐偏冷，比橡木暗、比深色橡木浅，处在一个很好用的中间调。

怎么用

它天生适合寒冷地区的建筑：雪原木屋、山地旅舍、松林哨站。冷褐色框配上积雪和深绿针叶，颜色非常和。

它也是“压深色”的好工具——白墙太亮时，用云杉窗框能把立面稳住，而不至于像深色橡木那样黑。

搭配

配云杉木、圆石、深板岩、云杉木窗户板是标准北欧组合；想加暖意，就在窗内放灯笼或营火。

和白桦木窗户混排可以做“深浅双色立面”，一个压重、一个提亮。

冷褐框在雪地里对比清楚，不会像浅色木料那样被雪吞掉；如果你在雪原建村，用它比用白桦窗更稳，夜里也更耐看。
