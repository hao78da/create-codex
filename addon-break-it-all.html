Create: Break It All

附属模组 · 让扳手能拆掉几乎所有方块

这是什么

Create 里扳手本来就有一个「拆」的功能，但默认只对 Create 自己的方块 生效。 Break It All 把这个限制放开：装上之后，绝大多数非自然方块（原版机器、箱子、炉子、别的模组的方块） 都能用扳手拆走。

类型：纯行为模组，不添加任何物品、方块、配方。装进 mods 即可，没有界面也没有配置。

能拆什么

  • 原版的机器和容器：熔炉、箱子、漏斗、发射器、活塞……
  • 其它模组的方块：只要那个方块不是「自然生成的那种」（草方块、石头、矿石这一类），基本都能拆
  • 拆下来是原方块本身，会掉进背包，不是变成掉落物散在地上

为什么要有这个

Create 的工厂搭起来之后，改布局是常事。原版拆方块要带精准采集的镐子，机器一多就很麻烦； 这个模组把「扳手拆 Create 方块」的便利直接扩大到整台生产线。

注意

  • 它不改变掉落规则，也不给方块加耐久——拆的是方块本身
  • 带容器的方块（箱子、桶）拆走后内容物会跟着走
  • 版本：目前只发布 1.21.1（NeoForge），没有 1.20.1 版本
