分液池：把液体倒出来

参数

类型加工机
输入含液物品
输出液体 + 空容器

详细教程

怎么获得

分液池用铜板 + 安山机壳合成，是注液器的反向设备：把带液体的物品（桶、瓶、涂层食物）放进去，液体被倒出，空容器留下。

它下方或侧面要接管道/储罐接收倒出的液体，否则液体浪费。

怎么用

用途：把水桶倒成空桶、把装满的瓶子倒空、回收涂层、给「灌装 → 使用 → 回收」的循环产线收尾。

和注液器成对使用：注液器灌满 → 物品被使用/加工 → 分液池倒空 → 空容器回到注液器，形成闭环。

常见坑

第一坑：没有接收容器，倒出来的液体直接消失。第二坑：物品本身不含液体，分液池什么也不做，看起来像坏了。

第三，倒出的液体种类必须和管道系统兼容，混线会污染储罐。
