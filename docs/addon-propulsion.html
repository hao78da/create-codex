Create: Propulsion

附属模组
给机械动力加一套飞行器：推进器、机翼、线缆、光学镜头

这是什么

把 Create 的旋转动力变成推力：固体/液体燃料推进器、离子推进器、矢量推进器，配机翼、粘合与遥控结构；另有一条铂（Platinum）材料线和光学镜头（透镜、线缆）。

命名空间：createpropulsion　1.20.1 版本：本页物品与配方直接取自该版本的 jar。
