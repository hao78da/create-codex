转速控制器

Rotation Speed Controller
create:rotation_speed_controller方块动力与传动

给整条线定转速

参数

类型传动控制
应力0 SU/RPM
范围±256 RPM，默认 16

详细教程

怎么获得

工作台里一个精密构件压在黄铜机壳上，出一台转速控制器。精密构件要序列装配，黄铜机壳要黄铜板，两样凑齐才有这台控制器。控制器要夹在两根轴之间，两端都接上才会生效。

它本身不产生动力，只是夹在两根轴中间，把上游的转速改写成一个设定值再往下送。它夹在两根轴中间，上游的转动经过它被改写成设定值，再往后送出去。

怎么用

右键打开界面设定目标转速，默认 16 RPM，范围上下各到 256，负数就是反向转。右键开界面，默认 16 RPM，范围上下各 256，负数就是反向转，改完立刻生效。改完转速下游立刻变，机器正在加工也不会停下来。

应力影响为 0，但它改的是下游全部机器的转速，等于一次性决定了整条线的速度和应力占用。应力 0，但它决定下游全部机器的速度，等于一次给整条线定基调。

常见坑

它只能改转速不能凭空造动力，上游没有转动时设多少都没用，别把它当成电机。上游没有转动时设多少都没用，它不是电机，别指望它凭空造动力。

把转速拉高会同时抬高下游所有机器的应力占用，主干容量不够就会集体停摆，提速前先算账。拉高转速会同时抬高下游机器的应力占用，主干不够就集体停摆，提速前先算账。

官方教程 · 使用转速控制器

  1. 转速控制器将旋转力从其转轴传递至它上方的大齿轮
  2. 通过其侧边的面板，可以调节输出转速
