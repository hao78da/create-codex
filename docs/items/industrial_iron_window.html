工业铁窗户

Industrial Iron Window
create:industrial_iron_window方块装饰与建筑

工业铁窗户，铆钉铁框，厂房与机库的窗。

参数

材质工业铁
类型窗户（整块）
合成3 工业铁块 + 1 玻璃 → 2

详细教程

怎么获得

把工业铁块摆成三面包住一块玻璃：上方一块、下方左右各一块，一次做出 2 块窗户。工业铁块是 Create 里那种带铆钉、颜色发暗的机加工金属方块，做机器外壳时常用。

因为要三块工业铁块才换两块窗，它比木窗贵不少，属于“重点墙面专用”。

怎么用

它的框又厚又暗，带铆钉细节，天生属于重工业场景：厂房高窗、机库大门两侧、锅炉房、矿井提升机房。整排装上去，墙面立刻有“这是承重结构”的重量感。

它也很适合做半地下的采光井——暗框埋在石墙里，只有玻璃在发亮。

搭配

配工业铁块、安山机壳、切制安山岩、安山栏杆是完整的一套工业语言。

想要“用久了”的效果，就在局部换成锈蚀的工业铁窗户，新旧混排比清一色更有故事。

和工业铁块、机壳用同一种灰，整面墙会像一体铸出来的；想让它跳出来，就在窗洞外圈加一圈黄铜或铜。
