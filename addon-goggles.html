Create Goggles附属模组

把工程师护目镜做成头盔的一部分——不占饰品栏，还能保留原本的护甲值和附魔。

这是什么

Create Goggles（旧名 Create Plus）是机械动力的附属模组。它不加机器，只做一件事：让护目镜和头盔合体。

原版 Create 里，护目镜要单独戴，占一个饰品/头盔位置；戴上头盔就看不了应力。这个模组把两件合成一件：头盔 + 护目镜 → 目镜头盔，图标上也直接多了副护目镜。合成走的是「保留 NBT」的配方，所以原头盔的附魔、耐久、纹饰都会跟着过去。

前置：机械动力本体，装上即可用。

三套机制

① 护目镜头盔。工作台两格：头盔 + 工程师护目镜。皮革、锁链、铁、金、钻石、下界合金、龟壳、纸板、铜潜水、下界合金潜水，一共十种；下界合金那件要走锻造台。

② 装甲储罐。铜背罐 + 对应胸甲，得到该材质的装甲储罐。穿在身上既是胸甲又是压缩空气罐，放地上接上转动能就能充气，跟 Create 原来的背罐一样。

③ 护目镜纹饰。如果你不想换掉手里的极品头盔，可以只在锻造台给它加一层护目镜纹饰：7 钻 + 圆石 + 护目镜做出模板，之后「任意头盔 + 护目镜 + 模板」即可；不想要了，用改装清除器（两个黄铜锭）点掉。
