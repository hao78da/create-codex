烈焰蛋糕胚

Blaze Cake Base
create:blaze_cake_base物品杂项

还没浇岩浆的蛋糕胚。

参数

工艺压块
材料蛋 + 糖 + 煤渣粉
状态半成品

详细教程

怎么获得

把鸡蛋、糖、煤渣粉各一份丢进压块机，压几下就出一块烈焰蛋糕胚。压块机要接旋转动力，转速不用高，能转起来就行，但方向别接反。压床里放蛋、糖和煤渣粉，压出来的就是蛋糕胚。

煤渣粉来自粉碎轮磨煤，鸡蛋靠养鸡或跑村庄，糖用甘蔗熬。三样材料都不稀罕，真正麻烦的是压块机本身要先搭起来，还得有稳定的动力源。它只是半成品，直接喂燃烧室不会点着。

怎么用

它只是半成品，还要走注液：把蛋糕胚放在注液器下方，注入岩浆，才变成能喂燃烧室的烈焰蛋糕。注液器的喷嘴要正对物品，偏一格就浇不上。用注液器浇上岩浆才变成真正的烈焰蛋糕。

岩浆用量不算小，用软管滑轮直接从岩浆湖抽最省事，比一桶桶拎快得多。做好的蛋糕攒一箱，燃烧室超热时随手就能补。一次压一组，装罐前先算好燃烧室的数量。

常见坑

别把蛋糕胚直接喂燃烧室，它不认这个半成品，喂进去只会掉在地上浪费。必须先把岩浆注满，成品才有效。煤渣粉要的是粉碎过的煤，原煤丢进去不合。

压块机里三样材料是同时消耗的，少一样就卡住不动；先检查输入箱有没有断供。注液器的岩浆也要持续供，断流会停在半途，蛋糕胚白搭。放进熔炉只会烧成灰，它不能靠烧制升级。
