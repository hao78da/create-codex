列表过滤器

List Filter
create:filter物品红石与控制

列表过滤器：让机器只认某些物品。

参数

配方铁粒×2+羊毛
用途机器过滤槽

详细教程

怎么获得

有序合成：中排三格摆铁粒、羊毛、铁粒，铁粒由铁锭拆、羊毛剪羊而来，成本很低，可以按打做。

它是通用部件，插进各种机器的过滤槽里才生效；做之前先想清楚要过滤什么，因为一个过滤器只装一份清单。

怎么用

右键打开配置界面，可以把物品逐个放进去，也能引用另一个过滤器的清单，或者按「物品集合」匹配；配置好的过滤器放进机器槽位，机器就只处理清单内的物品。

它常插在漏斗、溜槽、智能管道、打包机这类设备的过滤槽里，是自动化分拣最基础的一环。

搭配

和属性过滤器分工：列表过滤器认「具体物品」，属性过滤器认「可熔炼、可食用」这类类别；两条一起用能写出很细的规则。

分拣线常见做法是每个出口一个过滤器 + 一条传送带，把不同产物分别送进对应的箱子；清单改了记得重新配置，旧清单会一直拦着。
