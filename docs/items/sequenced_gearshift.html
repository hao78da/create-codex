可编程齿轮箱

Sequenced Gearshift
create:sequenced_gearshift方块动力与传动

按程序表执行动作的齿轮箱。

参数

材料黄铜机壳 + 齿轮 + 电子管
控制红石触发一次
读取比较器看进度

详细教程

怎么获得

无序合成：一个黄铜机壳、一个齿轮、一根电子管；黄铜机壳要铜锭加锌锭混出的黄铜，电子管则要磨制玫瑰石英和铁板。三步材料都要备齐。

它是自动化里最像「编程」的方块，做复杂机械之前先备两三个；一个只能跑一张时序表，多段动作要串多台，别指望一个顶全部，串起来才够用。

怎么用

右击打开设置面板，把指令按顺序排好：等待新脉冲、延迟一段时间、旋转指定角度、驱动活塞或滑轮、停止，一共五类，每条都能调速度档。

接上红石信号它才执行，跑完停在待机状态，再来一次信号才重跑；用比较器读它的输出，能知道当前跑到第几步、还剩多少，别拿长信号反复触发。

进阶

旋转指令按角度算，适合做分度盘、旋转展台和精准转向；驱动指令则把活塞、绳索滑轮、起重机杆当成一个动作来编排，两者可以混排。

速度档分 1× 和 2×，正反转都能选；调试时先用 1× 慢慢看动作对不对，确认顺序无误再提速，能省下大量拆装时间，也少坏几个零件。

官方教程 · 使用可编程齿轮箱来控制转速

  1. 可编程齿轮箱能够根据玩家设置的预设时序表来传递旋转
  2. 对其右击可以打开设置面板
  3. 接受红石信号时，它会开始执行其内部已配置好的时序指令表
  4. 当完成时序指令表后，它会进入待机状态，再次接受红石信号后，它才会再次执行时序指令表内容
  5. 红石比较器可以读取当前时序指令表完成进度
