稀有包裹

Rare Package
create:rare_package物品物流与仓储

包裹系统里的稀有件。

参数

类型包裹产物
获取打包/任务奖励
用途拆出稀有物

详细教程

怎么获得

它不是合成品，属于包裹系统里的稀有产物，通常由打包机、重新打包机在处理特定物品时产出。具体概率和条件由整合包决定，资料库里查不到配方。它没有配方，只能从打包机的随机产出里碰运气。

普通包裹是牛皮纸色，稀有包裹多一圈暗纹或异色封条，摆在一起能一眼分辨。收到时先别急着拆，看看封条颜色再决定。外观和普通包裹不同，封条是暗色的。

它也可能作为任务奖励或战利品出现；不同整合包给的路径差别很大，先看任务书比翻配方书有用。拆开能得到稀有材料，具体内容每次不一样。同一批包裹里开出什么全看运气。

怎么用

它的用途是拆开：拿在手里右键或放进拆包机，会掉出比普通包裹更好的东西。做自动拆包线时，把它单独分流到一条支线，别和普通包裹混着拆。想稳定刷它，得先搭一条完整的打包线。

配合包裹过滤器和传送带，可以按封条颜色把稀有件挑出来，再送进单独的箱子。产量不高，专门做一条线有点奢侈，手工拆更实在。包裹不能堆叠，仓库里要留单独的格子。

想囤着等配方更新也行，包裹不会过期，堆在仓库角落不占机器。别把它当普通包裹寄出去，寄走就没了。想留一只做样品，最好单独放进展示框。拆封后别再塞回打包机里。

常见坑

别把稀有包裹丢进普通拆包机的大流里，混在一起容易看漏，最后当普通货拆掉。分流时先用过滤器挑颜色。拆之前先存档，开出不需要的东西也能回退。

它不是材料，别指望用它合成别的东西；配方书里没有它的位置。拿到就拆，或者专门存一箱。它占的是包裹栏位，物流线上要单独分拣。分拣器要按包裹类型单独设一条支路。

包裹怕水也怕漏斗乱吸，传送带末端记得加个缓冲箱，别让它在漏斗里排队堵住整条线。数量少的时候留作展示，别急着拆。拆开的材料直接进仓库，别堆在机器口。

获取方式

这个物品没有合成配方：它由工具或机器直接生成/放置（例如用扳手、连接器、部署器，或作为其他配方的产物）。具体见上方教程。
