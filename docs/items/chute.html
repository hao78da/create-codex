详细教程

怎么获得

两张铁板夹一颗铁锭，工作台一次给出四个溜槽，前期就能凑出一组。铁板由铁锭在压床上轧成，仓库里常备几块板比现做省事，落差几格先量清楚。

铁紧的时候别一次做满，先拿两个把熔炉到箱子的短程接上，跑顺了再扩产。剩下的溜槽留着给分液池回液，急用时就不用临时去轧铁板。

怎么用

溜槽只管垂直方向：上口贴着漏斗或容器，下口落进箱子，中间靠一节节堆叠往下延。落差超过一格时每一格都要放，中间空着物品就卡在缝里。

拿扳手右击溜槽能开一扇观察窗，物品滑过时看得清；再用工业铁块右击，还能把它包成机壳外观。戴上护目镜能看出物品往哪个方向走。

常见坑

对着另一节溜槽的侧面放，才会变成斜向溜槽；随手一插很容易接不上，拐弯前先想好落点。斜向段拉得太长，物品会堆在接缝处。

末端被方块堵住，物品就只能从侧面取走，别指望它自己拐弯。想让物品往上走，得在下面加一台鼓风机，先接短管试吹再接长的。

官方教程 · 使用溜槽向下运输物品

  1. 溜槽可在两个容器之间垂直传输物品
  2. 使用扳手右击可以在溜槽上设置观察窗
  3. 工业铁块可用于装饰溜槽
  4. 对着另一个溜槽的侧面放置溜槽，将会放置下一个斜向的溜槽
