Sophisticated Backpacks Create Integration

附属模组 · 让背包能被 Create 的动态结构识别

这是什么

和上面那个是同一个思路：兼容补丁，把 Sophisticated Backpacks 的背包接到 Create 的动态结构上。

类型：纯行为模组，无物品、无方块、无配方。前置：Sophisticated Backpacks + Create。

解决了什么

  • 背包放在车厢/结构上时，能被 Create 当作容器处理，不会因为结构移动而丢失
  • 背包里的物品与升级保留

怎么用

  • 把背包放在 Create 的结构上，按平时的方式粘住
  • 结构移动时背包跟着走，右键仍能打开原界面

注意

  • 只处理「动态结构上的容器」这一个问题，不改背包本身的容量或升级
  • 版本：1.20.1（Forge）
