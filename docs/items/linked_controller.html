无线红石遥控器

Linked Controller

能揣在兜里的无线红石面板。

参数

材料6 木按钮 + 红石链接器
类型手持遥控
频道9 个按键

详细教程

怎么获得

工作台上上下各排三个木按钮，中间那格塞一块红石链接器，六块按钮加一个链接器合出一只遥控器。木按钮便宜，真正贵的是那块链接器，坏了心疼的也是它。六个木按钮围成一圈，中间放一只红石链接器。

拿在手上右键就弹出一张九宫格按键面板，每个键能绑一个频道。频道由接收端的链接器决定，遥控器只是发信的一方，本身不产生红石信号。右键打开界面写频道，和接收端编号一致才通。

怎么用

先在目标设备旁放一个红石链接器，设好频道；再把同样的频道绑到遥控器上某个键。按下按键，远处那台机器就收到一次无线红石信号，中间一根线都不用拉。两台设备之间不用拉线，隔着墙也能传信号。

车站道岔、山顶信号灯、远处的水泵，都能用一只遥控器管起来。配合遥控器讲台把它固定在值班台上，人走开设备也不会失控，交接班也省事。一个接收端能记多个频道，做总闸时很方便。

常见坑

频道绑错是最常见的失误：接收端的链接器换了频道，遥控器不会自己跟着变，按下去毫无反应，还以为是没电。频道号写错一位就整片失灵，抄号码前先记在纸上。

它是手持物品，别顺手丢进箱子忘了；丢了要重做，六个按钮加一块链接器的料又得重新凑。收发距离也有限，隔得太远或跨维度就收不到。它只转发不放大，长距离还是得靠红石中继。
