翻牌显示器

Display Board
create:display_board方块红石与控制

翻牌显示器：会翻字的机械屏幕。

参数

配方安山合金×2+电子管→2
动力需旋转力

详细教程

怎么获得

有序合成：上排三格摆安山合金、电子管、安山合金，一次出 2 块。安山合金便宜，电子管稍贵，做一面屏的成本主要看电子管产量。

它是机械件，装上之后要接旋转力才能翻字，所以别忘了在背后接一根轴或小齿轮。

怎么用

用剪贴板写静态文字，用显示链接器接动态数据；染料可以逐行上色，空手点某一行就把它清空，排版很自由。

屏幕会按行翻牌，文字长度受面板宽度限制；做站台信息板时一行写车次、一行写时刻，比一块大牌子清楚得多。

搭配

和显示链接器是标配：一块屏接多个链接器分别显示库存、产量、订单；链接器通电可以冻结刷新，方便对比两个时刻的数字。

和置物板搭配做「样品 + 名称 + 数量」的货架，和工厂仪表搭配做生产看板；动力不足时字翻到一半会卡住，看到半翻的牌就是该查转速了。

官方教程 · 使用翻牌显示器

  1. 翻牌显示器是告示牌的可扩展替代品
  2. 它们需要旋转力以供运作
  3. 可以使用已书写的剪贴板设置静态文本
  4. 使用显示链接器显示动态文本
  5. 可以使用染料来改变单行的颜色
  6. 可以通过空手点击来重置单行内容
