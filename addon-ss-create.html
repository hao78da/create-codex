Sophisticated Storage Create Integration

附属模组 · 让 Sophisticated Storage 的箱子能挂在 Create 的动态结构上

这是什么

这是一个兼容补丁，本身不加任何物品或方块。它做的事只有一件： 让 Sophisticated Storage 的箱子、桶、背包能被 Create 的动态结构（车、船、飞行器）带着走。

类型：纯行为模组，无物品、无方块、无配方、无界面。必须同时装 Sophisticated Storage 与 Create。

解决了什么

  • 原版 Create 的动态结构只认自己的方块；别的模组的容器挂上去会掉
  • 装上这个补丁后，Sophisticated Storage 的箱子能固定在车厢上，随车移动
  • 箱子里的物品、升级、设置都保留

怎么用

  • 正常把 Sophisticated Storage 箱子放在 Create 的车厢/结构上
  • 用胶水（Create 的 super glue）或结构方块把箱子粘住，它就会跟着结构一起动
  • 打开箱子还是原来的界面，存取物品如常

注意

  • 它只负责「挂上去不掉」，不做跨维度或跨存档的搬运
  • 版本：1.20.1（Forge/Fabric）
