详细教程

铺成桌面

黄绿桌布铺在方块顶面，就成了温室的育苗台，和作物、藤蔓、树叶是同一种绿，摆在那里像是从花架上长出来的一层。它比深绿亮，放在玻璃温室里不会显得阴；比纯绿活泼，适合「产出、分拣」的台面。

底下垫石砖或安山岩台面最稳，四周留一圈走道，别让布边贴着泥土——土色会把黄绿衬脏。

摆东西与开店

台面上摆四件展示：种子袋、成熟作物、成品果篮。做成商店时，黄绿桌布最适合农场的配货台：顾客在这里下单，货物由后方的打包机封包，再经物流送走，人不用进田里就能取货。

场景与搭配

黄绿 + 原木 + 玻璃 = 标准温室；和草方块、树叶同色时要用白墙或深色木柱隔开，否则整片糊成一团。作为分区标识，黄绿代表「农业/生长」，和青色的「水」、黄色的「警示」区分得很清楚。

  • 温室的育苗台、配货台铺它，和作物是同一套绿色。
  • 布边别贴着泥土，土色会把黄绿衬得发脏。
  • 当分区色用时，黄绿只管农业，别和绿色混在同一条动线上。
