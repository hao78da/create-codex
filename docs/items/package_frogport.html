详细教程

怎么获得

合成表竖着三段：顶端黏液球、中间物品保险库、底端安山合金，成品一个蛙港；保险库本身要两块铁板夹木桶，所以蛙港的门槛其实压在铁和黏液上。

黏液球找史莱姆，保险库要压床压铁板；先在物流区备好这两样，一次做四五个才能撑起一张像样的锁链网络。

怎么用

先右击一条锁链登记网络，再在锁链附近放置蛙港，它就会加入这张网；包裹进入网络后会自己寻路，找到地址匹配的蛙港再落下。

蛙港能直接访问正下方的容器，把箱子放在它脚下就能收发货；它也可以和打包机串联，物品打包后直接上线，不需要玩家手动投递。

进阶

用剪贴板右击蛙港可以抄下它的地址，再把地址写进包裹或仓储发报机的订单里，就形成了定点投送；地址不匹配时包裹会挂回锁链，等下一个匹配的蛙港。

如果整张网里没有有效目的地，包裹会在原地打转，所以要定期清理废弃蛙港；一条锁链可以挂多个蛙港，但每个都要有独立地址才好分拣。
