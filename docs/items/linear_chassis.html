轴向底盘

Linear Chassis
create:linear_chassis方块动态结构与载具

带粘面的一排底盘，拖动整块结构。

参数

材料2 安山合金 + 3 原木
产量一次 3 个
粘面空手右击切换

详细教程

怎么获得

配方是 2 个安山合金加 3 块原木：上下各一个合金、中间一排原木，一次出 3 个；原木用哪种都行，成本很低，前期就能批量做上几组。

也可以用轴向底盘二号直接转换，省下重新摆料的麻烦；两种底盘外形一样，只是粘面初始状态不同，转换前先确认没有别的底盘连着。

怎么用

空手右击底盘的一面会把它设成粘面，再右击一次则把粘面换到对面；潜行空手右击可以取消，粘面能抓住前方一整排方块，最多一次抓 16 格。

用扳手右击能调抓取范围，按住 Ctrl 则一次调整所有相连底盘；粘面朝向哪边，动态结构就往哪边伸，范围调太长会抓到不该动的东西。

常见坑

只有粘面能抓方块，其余面必须靠强力胶才能粘住；胶要涂在真正贴合的那一面，涂在空气里等于白费，很多人摆完发现结构散了就是漏了这步。

相邻且朝向相同的底盘会自动连成一个整体，移动时一起动；想分开控制就把它们错开一格，否则一开动机器整排都会被拖走，转向不同的底盘不会互连。

官方教程 · 成组移动轴向底盘

  1. 相邻的轴向底盘可以相互连接在一起
  2. 其中的一个底盘若被移动，其余的底盘也会跟着移动
  3. 不同种类的底盘，或者是朝向不一致的底盘，将不会相连

官方教程 · 使用轴向底盘黏合方块

  1. 它的外露面可以变为黏性面
  2. 再次点击黏性面，可以将它的对面也变得具有黏性
  3. 空手潜行右击可以移除此面的黏性物
  4. 黏性面可以将此面前方的一长条方块黏住
  5. 使用扳手可以精确控制底盘的影响范围
  6. 按住 Ctrl 以调节所有底盘的影响范围
  7. 若想让底盘的其他面也能粘方块，你需要用到强力胶
  8. 利用这些机制，任何形状的结构都可以作为动态结构移动
