动态结构控制器

Contraption Controls
create:contraption_controls方块杂项

装在动态结构上的开关。

参数

材料按钮 + 安山机壳 + 电子管
类型结构开关
安装随结构装配

详细教程

怎么获得

工作台竖着放三格：最上面一格按钮，中间一份安山机壳，最下面一只电子管，竖着三格正好合出一块动态结构控制器。三样都不算贵，难的是电子管要先有黄铜。按钮、安山机壳、电子管竖着三格就成。

按钮用什么材质都行，木按钮、石按钮都认；安山机壳则是安山合金贴在去皮原木上做出来的。电子管要黄铜板和玻璃管，所以它其实是中期件，前期先攒材料。它贴在可动结构上，右键打开驾驶界面。

怎么用

它不是放在地上的机器，而是装在动态结构上的操作面板：结构转起来之后，站在旁边按它，整座结构就会按预设动作响应。装的时候要保证它跟着底盘一起被抓起，不能留在原地。装的位置要在结构外侧，朝玩家那一面。

做可动的门、升降台、旋转舞台时，把它装在结构侧面伸手够得到的位置，按钮朝向外部。装反了按钮朝里，结构一动就按不到，只能停下来再改。电子管是后期材料，前期做不出来。

常见坑

它必须依附在会被装配的方块上；单独摆在轨道边不接结构，按下去毫无反应。装之前先用装配站抓一次，确认它跟着动。没有动力源时按了也不动，先接好轴承。

它只提供“按一下”的信号，不供能也不拉线；别指望用它替代拉杆或无线遥控。结构里的红石要靠结构内部的线路自己走。多个控制器能装在同一台装置上，注意别互相抢信号。

官方教程 · 使用动态结构控制器

  1. 动态结构上的元件默认情况下总是启用的
  2. 动态结构控制器可以在运动时移动控制它们
  3. 它们能被放在动态结构中的任何地方
  4. 当方块化时，过滤器可以被更改成特定的目标元件
  5. 当它在实体化时收到了红石信号……
  6. ……目标元件将会一开始就被关闭
