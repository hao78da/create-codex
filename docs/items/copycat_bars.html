详细教程

怎么获得

它属于 Create 的伪装（Copycat）家族，同族还有伪装基底、伪装板、伪装半阶。这一族统一以锌为原料，在切石机里切成各种形状，是专门给“想要某种材质、又想要某种形状”的场合准备的。

拿到手时它是一根没有身份的白模栏杆，需要你自己指定它长成什么材质。

怎么用

手里拿着任意一种方块，对着伪装栏杆右键，它表面就会变成那块方块的样子，但形状仍然是栏杆的杆与立柱。于是你可以做出石栏杆、木板栏杆、砖栏杆，甚至用矿石块做栏杆。

它解决的是“某种材质在原版里没有栏杆形态”的问题：想要一整套大理石栏杆，原版没有，伪装栏杆可以。

搭配

最典型的场景是庄园与神殿：石柱之间配石栏杆，砖墙之间配砖栏杆，让整段围栏和建筑同材质，而不是硬插一段铁栏杆。

和伪装板、伪装半阶一起用，能把一整段墙体做成“看起来是石造、实际是伪装件”的效果。
