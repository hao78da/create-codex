装配过的动力矿车

Furnace Minecart Contraption
create:furnace_minecart_contraption物品列车与轨道

烧煤自走的矿车结构。

参数

底座动力矿车
燃料煤/木炭
类型动态结构

详细教程

怎么获得

先在轨道上放一辆动力矿车，把要带走的方块、箱子、灯装在它上面，再用矿车装配站把整坨结构装成动态结构，最后用扳手取下。装配前把熔炉口朝上，燃料和原料都得从上方塞进去。

取下来的物品形态就是这辆装配过的动力矿车。底座那一格必须是动力矿车——用普通矿车装出来的，是另一种不带动力的版本，外观几乎一样但不会自走。取下来之后它还是一辆能放回轨道的矿车，不会变成方块。

怎么用

放下后它会重新铺开成一座结构，右键往里塞煤或木炭，它就会沿着轨道自己往前开，不用外力推，也不需要铺动力轨道。它有炉子但不会自己烧，得先往炉里放煤再放矿石。

适合做矿洞小火车、观光车头、短途货运：车头烧煤自走，后面挂几节装货的车厢，一条支线就活了。站台之间不必再拉长长的传送带。长距离跑一趟能烧完一组矿，比随身带熔炉省事。

常见坑

结构越重越慢，堆太多方块会爬不上坡；转弯别太急，矿车的转弯半径固定，急弯会把结构卡在轨外，还得拆了重装。爬坡时速度掉得厉害，坡道最好铺成缓坡而不是台阶。

取下之前先清空箱子，否则里面的东西会散落一地；装配站要贴着矿车放，隔两格就抓不到，装出来的结构也不完整。取下前把炉里的成品掏干净，否则会跟着结构掉在轨道上。
