详细教程

怎么获得

小齿轮用木板 + 传动轴合成，是最便宜的传动件。它必须咬合在另一只齿轮或大齿轮上才能传力：两个齿轮并排贴住，转向相反、转速相同。

齿轮也可以直接套在传动轴上（潜行放置），变成「轴上的齿轮」，用来和旁边的齿轮咬合。

怎么用

齿轮的核心作用是改向和变速：小齿轮带大齿轮 → 降速增扭；大齿轮带小齿轮 → 升速减扭。齿轮咬合时相邻两个转向相反，所以一条齿轮链可以做出各种转向组合。

它也是「过渡件」：机器和轴不在一条线上时，用齿轮把动力拐个弯送过去。多个齿轮串联时注意每个咬合点都会传递转速，设计齿轮比就是设计整条产线的速度。

常见坑

齿轮不咬合就不传力：隔一格、错一层都无效，很多人以为装上就转。第二个坑是方向搞反 —— 小带大是降速，想要高速却装反了，机器会慢得离谱。

第三，齿轮链太长会损失？不会损失，但每级咬合都占空间，紧凑布局时容易和机壳、带子打架。最后，大齿轮和小齿轮的咬合半径不同，摆放位置要按齿距对齐。
