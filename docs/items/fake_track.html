用于地图上的轨道标记

Track Marker for Maps
create:fake_track方块列车与轨道

地图轨道标记：只画在地图上的轨道。

参数

来源仅指令/创造
用途地图渲染

详细教程

怎么获得

它没有合成配方，也不是正经的轨道方块：没有任何工作台图纸能做出它，玩家拿到的途径只有指令或创造模式。

它的定位是「地图渲染用的替身」——用来在地图上画出一条轨道形状，而世界里不需要真的铺铁轨。

怎么用

它没有碰撞、可以被替换，放下去不会挡路也不会挡住方块放置；主要用于地图绘制与装饰性线路示意；它只改变地图上的图案，对世界里的方块没有任何影响。

真正的运输还得靠列车轨道；假轨只在「要一张好看的线路图」时才有意义，比如站厅墙上的线路示意图。

常见坑

别把它当轨道用：矿车和列车都不会认它，放上去也不会有任何运输行为，铺一地只会得到一张空图。

它在生存里没有正常来源，别为了它去翻配方表；要做线路图又不想要实体轨道，直接在地图界面画更省事。

获取方式

这个物品没有合成配方：它由工具或机器直接生成/放置（例如用扳手、连接器、部署器，或作为其他配方的产物）。具体见上方教程。
