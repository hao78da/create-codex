详细教程

怎么获得

资料库里没有它的工作台配方，也查不到切石配方，生存里做不出来。它一般随整合包或创造物品栏发放，属于搭建伪装结构时的底料。切石机放一块锌锭，就能切出伪装基底。

外形是一块没有贴皮的素方块，六面都是灰白底模，和切出来的半阶、板子颜色一致。拿到手先别急着贴，它更像是给其他伪装件打样的母版。它是伪装系列里最厚的一块，用来承接半阶和板。

想要可用的伪装件，还是走切石机：一块锌锭切出半阶或板子，比找基底实在。基底本身在多数整合包里只是过渡材料。贴皮方式和板一样，手持方块右键就行。

怎么用

它的用法和同系列一致：手持目标方块右键，表面就换成那块方块的材质。换成石头就是石墙，换成木板就是护墙板，一块方块能演好几种材料。贴完一面再贴另一面，两面会记住不同的材质。

做大面积伪装时，先铺基底再分区贴皮，比一块块切半阶省料。墙面、柱面、天花都能用，贴完远看是一整片材质，近看才有拼接缝。摆放时先放基底，再把半阶或板扣上去。

和伪装板、伪装半阶混用时，让基底走大面、板子走收边，交界处的缝能藏住，整体不会显得碎。拆基底会带走上面贴的东西，先拆上层。拆之前先记住哪一面贴了什么材质。

常见坑

空手右键没有反应，必须手里拿着方块才会贴皮，这一点和半阶、板子完全一样。贴错只能再覆盖一次，没法一键还原。它不承重，搭高台时下面要垫真方块。

它是伪装件，不带任何功能：不导电、不挡爆、也不当机器外壳。想走红石线还得在墙里预留管道，别指望它帮忙。和半阶、板混用时注意厚度差，接缝会露出来。

没有配方时别在配方书里死磕，去翻整合包的任务说明。拆下来只掉素块，之前贴的材质不会跟着回来。整面墙想做同一种材质，基底是最省材料的一层。
