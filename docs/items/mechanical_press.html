动力冲压机：把材料压成板

参数

类型加工机
输入旋转力 + 物品
输出板 / 压制成型

详细教程

怎么获得

冲压机由安山机壳 + 活塞/压头一类零件合成，放下后顶部或侧面接传动轴，正下方要放一个能承接物品的方块：置物台、工作盆或传送带。

它不需要红石信号，接上动力就持续工作；物品从下方送入（漏斗、带子、手丢），压完的产物留在原地或掉出来。

怎么用

冲压机做两件事：把锭压成板（铁板、铜板、金板、黄铜板），以及把物品压制成型（安山合金压块、纸浆压纸板等）。它是「板」类材料的唯一来源，几乎所有机壳都要先有板。

典型产线：熔炉/压床产锭 → 带子送到压床下 → 压成板 → 带子送走。压床可以连续工作，转速越高压得越快，应力消耗固定。

常见坑

第一坑：下方没有承接方块，压床空砸不产出。第二坑：把物品放在旁边的地上而不是置物台/带子上，压床只处理正下方那一格。

第三，压床会把带子上的物品截停加工，带子速度太快或物品太密时会排队；产线设计要留缓冲。第四，压床本身不存物品，前端断料就空转，最好配漏斗做缓冲仓。

官方教程 · 使用动力冲压机处理物品

  1. 动力冲压机可以处理位于其下方的物品
  2. 在其下方丢入物品，或者将物品放在置物台上，都算作有效的物品输入
  3. 若物品位于传送带上……
  4. 冲压机会使物品停下，然后自动处理这一物品
