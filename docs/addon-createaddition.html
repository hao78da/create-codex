附属模组
把 Create 的动能接进电力系统

这是什么

最老牌的 Create 扩展之一：用电动马达把应力换成电力、用交流发电机再把电力换回应力，中间靠电线、线轴和连接器组网。另附轧机（压板）、生物质燃料链和一整套金属棒板。

命名空间：createaddition　1.20.1 版本：本页物品与配方直接取自该版本的 jar。
